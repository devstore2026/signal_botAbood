# Abood Trading — Continuous Cards

## نطاق هذه النسخة
تزيل هذه النسخة حجب البطاقة بسبب Warming up أو عدم وصول 3 تكات جديدة. لكل طلب إشارة صالح من الواجهة النشطة تُنتج BUY أو SELL مع صورة، باستخدام أحدث أسعار متاحة. هذا ضمان لمسار القرار البرمجي، لا ضمان لشبكة Telegram أو تشغيل Render أو صحة توقع السوق.

## كيف يُختار الاتجاه؟
1. عند وجود بيانات حديثة كافية وسياق دقيقة مكتمل: يعمل محرك M1 + micro momentum السابق كما هو.
2. عند توافر عدد قليل من التكات أو تعارض شروط المحرك الانتقائي: تقدير قصير من EMA3/8 وسرعة الحركة الفعلية زمنياً والزخم وعدم توازن التكات وRSI. لم يعد مطلوباً 80 تكة أو دقيقة كاملة لإرسال البطاقة.
3. إذا كان آخر سعر قديماً: تحلل أحدث نافذة مخزنة ويظهر CACHED مع عمر المصدر. لا تغير الخوارزمية وقت السعر القديم لتوهم أنه جديد.
4. عند صفر أسعار أو سعر واحد: لا توجد معلومات كافية لتوقع اتجاه السوق. تُرسل صورة تجريبية DEMO ONLY، باتجاه آخر بطاقة للزوج/المدة، أو UP افتراضياً إن لم توجد بطاقة سابقة. هذا اختيار عرض افتراضي صريح، وليس تحليل تداول ولا توصية بالدخول. لا يُستخدم سعر وهمي ولا قرعة عشوائية.
5. الأسعار المسطحة تظهر FLAT مع تنبيه أن الاتجاه توضيحي وليس مدخلاً مؤكداً.

أصبح الجمع بين شرط «بطاقة دائماً» وصدق البيانات واضحاً: لا يُخفي البوت انعدام الأسعار ببطاقة تبدو كأنها تحليل حي. لا يمكن توليد إشارة سوقية موثوقة من صفر أسعار. لا نضمن نجاح 80% أو أي نسبة أخرى؛ هذه النسخة لم تخضع لتقييم سوقي حي.

## شكل البطاقة
```
Trading signal

Asset: EUR/USD (OTC)
Duration: 5 sec
Current time (UTC+3): 12:00:00
Direction: UP
Accuracy rate: ...
Source: ...
```
يبقى الشعار والصور وأزرار New signal وBack كما هي. سطر Source مهم ولا ينبغي حذفه: يفرق LIVE M1 وLIVE short-window وCACHED وDEMO ONLY وFLAT.

نسبة Accuracy ليست تحويل توافقات إلى احتمال وهمي. مع البيانات الحية تعرض نتائج PaperBook التاريخية أو «غير مقاسة بعد» عند نقص العينة. ومع البيانات القديمة/التجريبية/المسطحة تعرض «غير متاحة لهذا التقدير». لا تعرض 58% عشوائية لمجرد مطابقة صورة سابقة. /stats يبقى مقياساً ورقياً، لا ربح حساب أو احتمال الصفقة التالية، ولا تُسجّل البطاقات غير الحية ضمنه.

## التوقيت والضغط المتكرر
- الافتراضي SIGNAL_PREPARE_SECONDS=0: لا انتظار اصطناعي ولا اشتراط وصول تكات جديدة قبل إرسال البطاقة.
- إذا أردت وقت تحضير شكلي/لتجميع أسعار إضافية، ضع قيمة بين 0 و3 في المتغير الجديد. لا يؤثر ذلك على ضرورة إظهار البطاقة.
- أُلغي حظر 5 ثوانٍ بين الطلبات المتتابعة. يبقى BUSY لمنع تعارض الضغطة أثناء تحليل/إرسال قائم؛ النقرات المتزامنة المكررة تُدمج ولا يمكن تجاوز حدود Telegram.
- ANALYSIS_MIN وANALYSIS_MAX وFRESH_TICKS_REQUIRED وSIGNAL_COOLDOWN القديمة لم تعد بوابات إرسال في وضع Continuous Cards.
- سرعة الإرسال النهائية تتأثر بشبكة Telegram والرفع الأول للصورة والتخزين، وليست زمناً مضموناً.

## قاعدة عدم التكرار الجديدة
كان دفتر الإشارات يمنع أي طلب يستعمل نفس وقت المصدر؛ وهذا يتعارض مع طلبك إرسال بطاقة لكل ضغطة حتى عندما لا يصل سعر جديد. لذلك أصبحت الحماية مرتبطة بمعرف callback الخاص بالضغطة، وليس بوقت السعر:
- نفس تحديث Telegram لا ينتج بطاقتين.
- ضغطة جديدة تُسمح ولو استعملت نفس الأسعار المخزنة.
- تكرار BUY في سوق صاعد ليس سبباً لقلبها آلياً إلى SELL. إذا لم تتغير البيانات قد يتكرر الاتجاه ونفس الإحصاء التاريخي، ولا ننوّعهما بشكل مصطنع.
- الاستجابة الشبكية الملتبسة تسجل uncertain ولا تعاد تلقائياً لنفس الضغطة.
- ملف SQLite القائم متوافق؛ ينشأ جدول card_requests جديد ولا تحتاج حذف قاعدة بياناتك. الجداول الأقدم لا تستخدم لحجب البطاقات الجديدة. سجلات الطلبات تحتفظ بآخر 30 يوماً.

هذه ليست معاملة موزعة تضمن exactly-once مع Telegram، بل حماية عملية من تكرار نفس الطلب. بقاء الحماية بعد restart يتطلب بقاء ملف SQLite.

## النشر
1. أوقف النسخة القديمة، ولا تشغل polling مرتين لنفس التوكن.
2. ارفع محتويات مجلد abood_signal_bot، مع الحفاظ على Root Directory الصحيح في Render.
3. أبق BOT_TOKEN وPO_AUTH_FRAME وPO_WS_URL وSELF_URL في Render Environment. لا توجد أسرار أو .env في الحزمة.
4. Build: pip install -r requirements.txt
5. Start: python -u bot.py
6. Health: /health
7. جديد واختياري: SIGNAL_PREPARE_SECONDS=0

لا تغيير على الصور أو تصفية أزواج العملات OTC أو إعادة اتصال Feed أو ملفات Render. /status يعرض تشخيص البث؛ بطاقة DEMO لا تعني أن البث أصبح يعمل. إذا أردت أسعاراً حية فعلاً، قد يلزم إطار جلسة demo صالح محلياً. لا تشارك التوكن أو إطار المصادقة في المحادثة.

خطة Render المجانية لا تضمن 24/7، وself-ping ليس ضماناً رسمياً ضد السكون. ملفات SQLite/النتائج على التخزين المؤقت قد تضيع بعد النشر أو الإيقاف. لا تعد هذه النسخة بحل حدود الاستضافة.

## التحقق والخصوصية
26 اختباراً محلياً خارج الحزمة، بما فيها صفر/سعر واحد/5 تكات/سياق M1/أسعار قديمة، البطاقة المصورة لكل وضع، استبعاد DEMO/CACHED من الإحصائيات، وإعادة استخدام نفس الأسعار في ضغطة جديدة ومنع تكرار نفس callback.
الاختبارات لا تتصل بحسابك ولا بالمنصة ولا بتيليجرام. نجاحها ليس دليلاً على نسبة فوز أو تحسن مالي. الحزمة نظيفة: لا اختبارات أو كاش أو بيانات تجريبية أو جلسات. جرّب على Demo أولاً ولا تربط البطاقات التجريبية/القديمة بتنفيذ أموال حقيقية.
